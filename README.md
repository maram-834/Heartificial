# Heart Disease Prediction using Machine Learning

## Overview
A machine learning project that predicts the likelihood of heart disease based on
patient health data. The project focuses on data preprocessing, model training, and
performance evaluation.

## Key Features
- Data cleaning and feature selection
- Supervised learning models for classification
- Model evaluation using accuracy and other metrics

## Technologies
- Python
- NumPy
- Pandas
- scikit-learn

## What I Learned
- End-to-end ML workflow
- Evaluating classification models
- Working with real-world datasets
